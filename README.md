# 🚆 Project 1 — NMBS / SNCB Railway Punctuality & Delay Analysis

Full Project Documentation can be found in the [Infrabel_Punctuality](Infrabel_Punctuality) directory.

## Overview

This project analyzes Belgian railway punctuality data (H2 2025) using official Infrabel open data.

The objective was to move beyond simple delay counts and evaluate:

- Network-wide punctuality
- Station-level delay concentration
- Reliability consistency
- Delay volatility
- Systemic bottlenecks

## Core Analytical Focus

- Dimensional modeling
- Impact % calculation
- Delay standard deviation (volatility)
- Log-scale scatter analysis
- Heatmap time-pattern analysis
- Context-aware DAX measures

## Key Skills Demonstrated

- Advanced DAX
- Performance KPI modeling
- Data transformation in Power Query
- Analytical dashboard storytelling

## Tools Used

- Excel (Power Query)
- Power BI
- DAX
